# مفاتيح القرآن الكريم

مصحف تفاعلي وموسوعة قرآنية وإسلامية، من تطوير **محمد شعبان محارب**.

## أقسام المشروع الظاهرة في الواجهة
- المصحف والبحث في الآيات.
- البحث الموضوعي ومعجم الكلمات والمواضع.
- قصص الأنبياء والسيرة.
- مكتبة الفيديوهات.
- الغزوات والفتوحات والموسوعة الإسلامية.
- أدوات إضافية ومعلومات عن المشروع ومصادره.

## التشغيل والنشر
المشروع مبني كصفحة ويب ثابتة داخل `index.html`. يمكن مراجعة ملف الصفحة من المستودع وتشغيله محليًا، كما يمكن نشره باستخدام GitHub Pages بعد ضبط **Settings → Pages** على الفرع `main` ومجلد الجذر `/(root)`.

الرابط الحالي المذكور داخل الصفحة:
`https://mo444444444444444-coder.github.io/---/`

> اسم المستودع الحالي `---` غير واضح للمستخدمين. قبل تغييره، يجب إعادة ضبط رابط canonical وروابط النشر وفحص GitHub Pages حتى لا تتعطل الروابط القديمة.

## ملاحظات الجودة
- يُرجى التحقق من مصادر نص القرآن والتفسير والبيانات قبل أي تعديل على المحتوى الديني.
- وجود القسم في الواجهة لا يعني أن كل مصدر خارجي أو مشغل فيديو يعمل دائمًا؛ بعض الوظائف تعتمد على توفر الاتصال والمصدر.
- يجب اختبار البحث والتنقل والصوت والمقاسات على الهاتف والكمبيوتر قبل إعلان الموقع جاهزًا للنشر.
