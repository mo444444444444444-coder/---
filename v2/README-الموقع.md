# مفاتيح القرآن الكريم — النسخة الجديدة

**المنشئ والمطور: محمد شعبان محارب**

هذه النسخة هي الأساس الجديد للموقع، مع الحفاظ على النسخة القديمة كاحتياطي.

## أقسام الموسوعة المستهدفة
- المصحف الشريف
- البحث القرآني
- التفسير
- قصص القرآن والأنبياء
- معجم ألفاظ القرآن
- الأخلاق والقيم
- العلم والتفكر
- الإيمان والعقيدة
- الأسرة والمجتمع
- الدعاء والصبر
- السور المكية والمدنية
- الأجزاء والأحزاب والأرباع
- التلاوات
- القراءات والروايات

> لا يتم إدراج نصوص قرآنية أو نسبتها لمصادر تفسيرية إلا من مصادر موثوقة، مع فصل النص القرآني عن الشروح والمعلومات.
